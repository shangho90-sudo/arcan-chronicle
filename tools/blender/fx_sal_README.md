## 타이밍 (시전 시작 = 0, 명중 = 0.10 s = 일격참 동작 0.30 s)

| 시간 | 내용 |
| --- | --- |
| 0.00–0.05 | 실제 칼끝(`bladePoints()`)에 빛이 모이고 작은 빛 조각 4~6개가 칼끝으로 모임 |
| 0.05–0.10 | 칼끝 → 명중점으로 가는 백색 섬광이 지수 감속 곡선으로 늘어남(명중 순간 다 뻗음, 시전자를 따라감) |
| 명중 +0.00–0.03 | 넓은 백색 섬광(0.025 s)·방사 광선(0.035 s)·코어가 빠르게 나타남, 분홍 광선이 뻗어 나감 |
| 명중 +0.03–0.07 | 최대 발광 = 피해가 들어간 프레임(백색 면 + 분홍 방사 광선 가장 밝음) |
| 명중 +0.07–0.17 | 백색 면이 좁아지며 꺼짐(분홍 테두리만 남음), 방사 광선은 0.24 s까지 보라로 바뀌며 흐려짐 |
| 명중 +0.06–0.20 | 광선이 점점 가늘어지고(폭 0.2배까지) 어두워짐, 코어는 0.16 s에 사라짐 |
| 명중 +0.20–0.35 | 보라 잔광·가는 보라 광선·파편 소멸 (전방 섬광은 시전 0.30 s에 사라짐) |

게임에서는 스킬 데이터(`tools/skills2/gen.py` `nv_a1`)의 `fx` op `sal: 'cast'`(`len` = 몸에서 섬광 끝까지 최대 거리)를 타격 0.10 s 전(`at: -0.10`)에 띄우고, 섬광은 칼끝에서 **명중점**까지 이어집니다. 명중점은 `salfx.js` `salImpact(대상, 방향)` 하나로 계산(대상 앞면, 가슴 높이)해 빔 끝과 명중광 중심이 같은 점을 씁니다(2026-11-10). 피해가 들어가는 순간 `hit(..., {cast})`가 빔 끝을 그 점에 고정하고, 대상이 그 전에 죽거나 사라지면 마지막으로 유효했던 점을 유지합니다(빔이 갑자기 최대 길이로 늘어나지 않음). 대상이 없을 때만 몸에서 `len` m. 명중광은 `hit` op의 `fx.sal`: 가장 가까운 대상에 완성 명중광(`primary`), 추가로 맞은 대상에는 작은 보조 명중광(`secondary`: 0.62배, 가는 보라 광선 없음, 파편 5개), 아무도 안 맞으면 약한 소멸광(`whiff`: 코어·잔광만, 넓은 섬광·방사 광선 없음). 명중광은 월드에 고정되어 캐릭터를 따라가지 않습니다.

## 조절 값 (`js/salfx.js` `SAL`, 브라우저 콘솔에서 `SAL_FX`)

`white / pink / magenta / purple` 색, `intensity`(밝기), `length`·`width`(전방 섬광), `hitSize`(명중광), `speed`(재생 속도). 저사양(휴대폰 또는 '그래픽 효과' 꺼짐): 넓은 백색 섬광·방사 광선·분홍 주광선(별 모양)은 그대로, 전방 보조 광선·가는 보라 광선 숨김, 파편 14 → 6(보조 명중광 5 → 2), 응집 조각 6 → 4. '섬광 효과 줄이기': 밝기 0.6배.

## Unity로 옮길 때 (URP 기준 예시, 프로젝트 확인 후 조정)

- 재질: Unlit 셰이더 하나. 텍스처 `fx_sal.png`(sRGB 끔, 압축 없음 또는 고품질). `col = white*R*(1-0.7h) + lerp(pink, magenta, h)*G + purple*B*0.85`, 결과에 `intensity * fade`를 곱하고 알파 = `A * fade * 0.6`. 블렌드 `One OneMinusSrcAlpha`(밝게 더하면서 배경을 조금 눌러 Bloom 없이도 모양이 보임), ZWrite Off, ZTest LEqual, Cull Off.
- 가늘어짐: 광선 메시의 UV v를 광선 셀의 실제 중심(`fx_sal.glb.json`의 `cells.ray` = [u0, u1, v0, v1], 게임이 샘플링하는 glTF UV 기준: v 0.506~0.994, 중심 0.75) 기준으로 `1/thin`배 늘려 샘플링하고 셀 밖은 버림. (예전 0.25 고정값은 Blender UV 기준이라 glTF 내보내기의 v 뒤집기와 맞지 않아 광선 전체가 한꺼번에 사라졌음)
- 깊이: 정점을 시선 방향으로 1.3 m 당겨 그림(`DEPTH_BIAS`) — 자기 대상의 몸에는 가려지지 않고, 그보다 멀리 있는 벽·지형 뒤에서는 가려짐.
- Prefab: `Sal_Cast`(칼끝에 붙임: core·sheet·side MeshRenderer + 칼끝 빌보드 + 응집 Particle System 6개, Burst, 수명 0.055 s) / `Sal_Hit`(월드에 생성: rays·thin MeshRenderer + 코어·잔광 빌보드 + 파편 Particle System 14개, Mesh 렌더 모드 `sal_shard`, Stretched, 속도 3~7.5, Drag 5). 위 타이밍은 Animator 또는 스크립트 커브로.
- 연결: 공격 애니메이션의 타격 이벤트 0.10 s 전에 `Sal_Cast`, 타격 이벤트에서 맞은 대상 위치에 `Sal_Hit`. 풀링은 Prefab 단위로.

## 2026-11-10 혼합·깊이

- 넓은 섬광·방사 광선·명중 코어: 순수 가산(`One, One`) — 흰 면이 배경을 누르지 않고 그대로 밝게 더해짐. 나머지(빔·광선·잔광·파편)는 `One, OneMinusSrcAlpha`(부드러운 번짐이 배경을 살짝 누름). 전역 블룸·노출은 그대로.
- 모두 `depthTest` 켬·`depthWrite` 끔. 시야 방향으로 당겨 그리는 거리: 빔·광선 1.3 m, 넓은 섬광·방사 광선 2.0 m(대상 몸에 묻히지 않게, 벽·지형은 여전히 가림). 그리기 순서: 잔광 7 < 가는 광선 8 < 광선 9 < 방사 광선 11 < 섬광 12 < 코어 13.
- 후처리(`js/post.js`) 대비 곡선이 1.5보다 밝은 값에서 음수가 되어 아주 밝은 분홍(R·B 큼)이 초록으로 보이던 문제를 고침(곡선을 0~1에만 적용, 그 위는 그대로).
