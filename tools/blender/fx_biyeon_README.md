# 비연참 '비연파(飛燕破)' 부채꼴 검풍 이펙트 — 자산과 적용 안내

웹 게임(three.js)에는 `js/biyeonfx.js`로 적용되어 있습니다(`SkillFx.biyeon`). Unity 프로젝트는 이 저장소에 없으므로 Prefab은 만들지 않았고, 옮길 때 필요한 값은 아래와 코드 머리 주석에 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `tools/blender/fx_biyeon.py` | 생성 스크립트 (Blender 5.2 bpy, `python3 tools/blender/fx_biyeon.py`). 맨 위 값(`ARC`·`THICK`·`TILT`·`ARC_SEG`)으로 초승달 모양 조절 |
| `tools/blender/biyeon/fx_biyeon.blend` | 수정용 원본. 컬렉션 `BI_slash`(초승달) / `BI_ground`(바닥 궤적·고리) / `BI_hit`(십자 섬광·빛·티끌·파편). 재질 `M_biyeon`은 Blender 미리보기 전용 |
| `tools/blender/biyeon/fx_biyeon.fbx` | 다른 엔진용 메시 (axis_forward −Z, up Y) |
| `assets/fx/fx_biyeon.glb.json` | 게임 메시 (base64 GLB, 이미지 없음) + 아틀라스 칸 표 `cells` + 삼각형 수 `tris` |
| `assets/fx/fx_biyeon.png` | 1024×1024 아틀라스, 7칸(초승달·궤적·빛·파편·십자·고리·티끌). 색이 아니라 마스크: R = 흰 코어, G = 하늘색 본체, B = 청보라 번짐, A = 덮임 |

메시(게임 축 +Z = 공격 방향, +Y = 위), 합계 88삼각형:

| 메시 | 삼각형 | 기준점 | 역할 |
| --- | --- | --- | --- |
| `bi_crescent` | 56 | 바깥 날의 맨 앞 꼭짓점(날 끝 = 명중점) | 납작한 초승달 검풍(바깥 반지름 1, 112°, 가운데 두께 0.38, 끝은 뾰족) |
| `bi_trail` | 8 | 꼬리, 길이 1(+Z), 폭 1, 바닥(y 0) | 가운데 검풍 아래 땅을 스치는 가는 궤적 |
| `bi_ring` | 2 | 가운데, 바닥에 누운 사각형 | 준비 동작 때 발밑의 옅은 고리 |
| `bi_cross` | 2 | 가운데 | 명중 십자 섬광(카메라를 봄) |
| `bi_quad` | 2 | 가운데 | 칼끝 응집 빛·휘두를 때 섬광·명중 코어·잔광 |
| `bi_mote` | 2 | 가운데 | 위로 오르는 티끌(인스턴스 빌보드) |
| `bi_shard` | 16 | 가운데, 길이 1 | 명중 파편(인스턴스) |

색(`BIYEON` in `js/biyeonfx.js`): 흰색 `#FFFFFF`, 하늘색 `#8BE8FF`, 청보라 `#777BFF`, 옅은 하늘 `#DDF8FF`. 재질은 depthTest 켬, depthWrite 끔, 가산 + 약한 배경 어둡게(블룸 없이도 모양이 보이게). 바닥 궤적·고리는 4 cm 띄우고 polygonOffset(지면과 깜빡임 없음).

## 판정과 부채꼴의 관계 (단일 대상 유지)

- 피해는 지금처럼 투사체 하나(`proj`, 속도 13, 사거리 10, 폭 1.3, 관통 없음)가 처음 닿은 적 하나에게만 줍니다. 피해·쿨타임·MP·사거리는 그대로.
- **가운데 초승달 = 그 투사체**: `SkillProj`가 위치를 매 프레임 넘기고, 땅에는 가는 궤적이 따라갑니다. 가장 크고 밝습니다.
- **양옆 초승달 6개(저사양 4개) = 장식**: 휘두르는 순간부터 0.02~0.08초 차이로 ±16·32·48°(저사양 ±20·40°)로 2.3~3.2 m만 날아가며 느려지고 0.6초 무렵 사라집니다. 피해 없음.
- **명중 효과(십자 섬광·코어·잔광·고리·파편·티끌)는 실제 피해 순간에만**, 피해를 받은 적의 몸 앞(가슴 높이, `biyeonImpact`)에서 나옵니다. 그 순간 가운데 초승달은 그 점에 붙어 0.1초 안에 섬광 속으로 접힙니다. 허공이면 사거리 끝에서 0.25초 동안 퍼지며 흐려지기만 합니다.

## 타이밍 (시전 = 0 s, 휘두르기 명중 시각 0.22 s는 `nv_biyeon` 동작에서 읽음)

| 구간 | 시간 | 내용 |
| --- | --- | --- |
| 준비 | 0.00–0.12 | 실제 칼끝에 빛이 모이고 발밑에 옅은 고리 |
| 휘두르기 | 0.16–0.30 | 칼끝 흰 섬광 + 몸 앞을 가로지르는 넓은 초승달 |
| 발사·부채꼴 | 0.22–0.60 | 가운데 검풍 발사, 양옆 검풍이 시간차로 퍼졌다 흐려짐, 티끌이 오름 |
| 명중 | 대상 4.5 m일 때 0.38, 보통 0.35–0.75 | 십자 섬광 0.03초 만에 최대, 0.22초까지 접힘, 고리·파편 ~0.4초 |
| 사라짐 | 명중 + 0.2–0.7 | 청보라 잔광과 티끌이 부드럽게 사라짐 |

## 저사양

휴대폰 또는 설정 "그래픽 효과" 끔: 티끌 없음, 양옆 검풍 4개, 파편 5개. 가운데 검풍·궤적·휘두르기 섬광·십자 섬광은 유지. "섬광 효과 줄이기"는 섬광 밝기 0.6배.
